# 二、各渠道细节

## 2.1 合成（空白图纸路线）

- **空白军用图纸**：3 纸 + 1 墨囊 + 1 羽毛 → 3 张（有序配方 `P / PMP / F`）
- 可合成的 Epic 蓝图：
  - M82：空白 + 钻石 + 望远镜 + 紫水晶（无序）
  - RPG-7：空白 + 3 钻石 + 4 绿宝石（有序）
  - 防暴盾：空白 + 钻石 + 黑曜石 + 绿宝石
  - MP5K 接力者：空白 + 铁 + 铜 + 红石 + 紫水晶
  - 夜视仪：空白 + 科技数据 + 机械芯片 + 紫水晶
  - 黄蜂胸挂 / 防暴裤 / 军靴 / 面罩：空白 + 科技数据 + 机械芯片 + 碎布 / 皮革 / 铁锭 / 玻璃板
  - Crye AirFrame：空白 + 机械芯片 + 科技数据 + 紫水晶 + 红石
  - Crye JPC 2.0：空白 + 机械芯片 + 科技数据 + 凯夫拉 + 钻石

## 2.3 周本（本次新增，重要新来源）

入口：`/scriptevent daily:weekly`（或 SAPI 服务器战斗菜单跳转）；房间最多 8 人、30 分钟限时；倒地可被救援，真死退局但通关仍有奖励。

| Boss | 难度 | 护甲 | 金币（基础×倍率） | Epic 蓝图（第1格） | 传说蓝图（第2格） |
|---|---|---|---|---|---|
| 斯洛克（沙虫，20000 HP） | 困难 | 10 | 20,000×2 | **Python 谢幕 20%** | 特斯拉电弧 0% |
| 斯洛克 | 噩梦 | 20 | ×4 | **Python 谢幕 40%** | 特斯拉电弧 20% |
| 斯洛克 | 地狱 | 40 | ×8 | **Python 谢幕 50%** | 特斯拉电弧 50% |
| 莫加苏尔（30000 HP） | 困难 | 10 | 30,000×2 | **SCAR-H 剥甲者 20%** | MGL 0% |
| 莫加苏尔 | 噩梦 | 20 | ×4 | **SCAR-H 剥甲者 40%** | MGL 20% |
| 莫加苏尔 | 地狱 | 40 | ×8 | **SCAR-H 剥甲者 50%** | MGL 50% |

规则：
- 每人每 Boss 每周一次**固定种子 roll**（同一周内结果固定），只按**最高难度**结算；
- 先打低难度再打高难度会按最高难度"补差"，同一周内已拿到的蓝图不会重复；
- 周一 04:00（UTC+8）重置，奖励账本保留 12 周。

## 2.4 神话补给箱（Daily）

- 需要「神话补给密钥」开启；
- 内容：**5 张限定 Epic 蓝图合计 70%**（PKM / USAS-12 / M1014 泰坦壁垒 / G52 / 泰坦外骨骼 各 14%），其余 30% 为传说蓝图（电弧、堡垒三件套）；
- 密钥主要来源：SAPI 抽奖（高级箱 2%、限定池 3%、无人机池权重 2～3）、废墟箱（权重 10）、史诗箱 2%、传说箱 8%，神话箱自身 15% 返还。
- 摸金都市箱子品质分布 60/25/10/4/1%，**史诗/传说品质箱不含蓝图**，只有 1% 的神话箱给（且需密钥）。

## 2.5 副本奖励（Daily）

- 困难：完成时 **0.5%** 随机 Epic 蓝图；噩梦：**1.5%**；
- 按当日奖励倍率结算（前 2 次 100%、3～4 次 75%、第 5 次起 50%）；
- 随机池 5 选 1：**M82 / RPG-7 / 防暴盾 / 武士刀 / 库克锐弯刀**。

## 2.6 废墟箱 / 高级随机箱

- 「无品质废墟物资箱」（约每 6 区块、30 分钟刷新）：**1%** 追加一张随机 Epic 蓝图（同上 5 选 1）；
- 「高级随机箱」（仅非法制区）：**1%** 把其中一个物品位替换为随机 Epic 蓝图（同上 5 选 1）。

# 四、备注

1. **蓝图是消耗品**：造枪消耗 1 张；铁砧修理每张恢复最大耐久的 80%；无人机蓝图在机库组装时消耗，不是永久解锁。
2. 抽奖十连无折扣（1200×10 = 12000 等）；所有概率均为代码静态值，未经 Bedrock 实机验证。
3. 抽奖的"限定五件套"与 Boss/副本的"5 选 1 随机池"互不重叠：抽奖不出 M82/RPG/防暴盾/武士刀/弯刀。
4. 无人机限定池默认关闭，需管理员在控制台发布；周本按周结算，不可重复刷取同难度。
5. 摸金都市、废土事件、日常委托、自然灾害等系统**不直接产出 Epic 蓝图**（仅通过上面的箱子/副本/周本/Boss 间接获得）。
