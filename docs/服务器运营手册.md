# LOTM-MC 服务器运营手册

适用版本：SAPI Server `2.10.0`、Daily & World Events `0.16.0`、Apocalypse UI `1.1.0`、Extraction City `0.10.7`、Natural Disasters Standalone `1.3.3`。

本手册供服主和管理员使用。命令默认由玩家本人在游戏聊天栏执行；控制台执行依赖玩家来源的命令时可能无法识别目标玩家。

## 1. 管理员权限

```mcfunction
/tag @s add admin
```

撤销权限：

```mcfunction
/tag @s remove admin
```

拥有 `admin` 标签或 OP 权限的玩家会被识别为管理员。不要向普通玩家授予该标签。

## 2. 每日开服检查

1. 进入世界并等待约5秒，让行为包完成初始化。
2. 执行 `/scriptevent system:menu`，确认 SAPI 菜单可用。
3. 进入 SAPI 管理员控制台，确认 Daily Events 显示“已连接”。
4. 执行 `/scriptevent daily:admin`，确认日常管理菜单可用。
5. 执行 `/scriptevent extract:status`，检查摸金都市、怪物和物资箱。
6. 如启用自然灾害，执行 `/scriptevent sando_standalone:menu`。
7. 检查内容日志中是否持续出现 `failed`、`unavailable` 或 JSON 错误。

### 七日签到金币

默认七日循环奖励为：

| 天数 | 金币 |
|---:|---:|
| 第 1 天 | 2,000 |
| 第 2 天 | 2,500 |
| 第 3 天 | 3,000 |
| 第 4 天 | 3,500 |
| 第 5 天 | 4,000 |
| 第 6 天 | 5,000 |
| 第 7 天 | 8,000，并发放配置中的额外物品 |

每个七日周期共 `28,000` 金币。升级后，仍使用旧内置签到表的世界会自动换成新金额；管理员曾经手动设置的奖励不会被覆盖。可在“服务器运营管理 → 签到配置”中继续调整。

### 领地与安全区

玩家不能认领与管理员保护区或 Apocalypse 安全区重叠的区块。内置安全区坐标不依赖 Addon 心跳，即使联动暂时显示未连接，创建领地的服务端校验仍然有效。

### 社交、队伍与公会

社交功能的正式入口是“SAPI 主菜单 → 社交”，不另设好友、公会或私聊聊天指令。`/scriptevent system:social` 仅作为菜单打不开时的备用入口。

- 好友上限 50；好友关系、申请和公会数据跨重启保存，私聊不保存历史。
- 在线资料卡不显示精确坐标、金币、背包或装备。
- 队伍最多 4 人且不会持久化，服务器重启后自动解散。
- 队长从副本入口发起全队 Ready；所有成员必须在线、存活、未进入其他副本，并在 30 秒内同意。
- 队友在同维度且距离目标 40 格内时，共享击杀日常、动态事件、Boss 和副本贡献；副本通关奖励仍按个人独立发放。
- 创建公会默认花费 15,000 金币，上限 30 人，权限只有 Leader 与 Member。
- 公会基地坐标只用于导航/传送，不创建保护区。公会需要保护建筑时仍由 LandClaim 负责。
- 领地主人可在“地皮领地 → 当前地皮 → 设置访客出生点”设置观光落点。观光邀请不会赋予任何领地、容器、保险箱或载具权限。

### 掉落物自动清理

系统默认每 `10` 分钟清除主世界、下界和末地当前已加载区域内的全部地面掉落实体，并提前 `60`、`30`、`10` 秒发布全服提醒。该规则不区分物品来源和品质，玩家死亡掉落、蓝图、武器、弹药与任务奖励都会被删除且无法恢复。

| 命令 | 用途 |
|---|---|
| `/scriptevent system:cleanup` | 打开管理菜单 |
| `/scriptevent system:cleanup status` | 查看开关、周期和倒计时 |
| `/scriptevent system:cleanup on` | 开启自动清理并重置倒计时 |
| `/scriptevent system:cleanup off` | 关闭自动清理 |
| `/scriptevent system:cleanup now` | 打开立即清理二次确认 |
| `/scriptevent system:cleanup interval 10` | 将周期设为10分钟并重置倒计时 |

周期允许 `1～120` 分钟。所有设置修改和实际清理数量都会写入审计日志。

## 5. 新闻与动态事件

推荐从 SAPI 管理员控制台的“发布联盟每日新闻”，或 `/scriptevent daily:news_admin` 进入。管理员可以选择预设、修改地点名称并手动填写坐标。

查询与停止事件：

```mcfunction
/scriptevent daily:event list
/scriptevent daily:event nodes
/scriptevent daily:event stop
```

启动事件格式：

```mcfunction
/scriptevent daily:event start <template>
```

| Template | 事件 |
|---|---|
| `infected_attack` | 感染者袭击 |
| `survivor_rescue` | 幸存者救援 |
| `raider_ambush` | 掠夺者伏击 |
| `crashed_convoy` | 坠毁运输队 |
| `roadblock_clearance` | 路障清理 |
| `toxic_outbreak` | 毒性爆发 |
| `mutant_nest` | 变异巢穴 |
| `mercenary_blockade` | 雇佣兵封锁 |
| `fog_man_hunt` | 雾中人事件 |
| `goatman_hunt` | 山羊人事件 |
| `siren_head_hunt` | 警笛头事件 |
| `rebel_invasion` | 叛军入侵主城 |

例如：

```mcfunction
/scriptevent daily:event start siren_head_hunt
```

启动前确认 Apocalypse Mobs 与 Apocalypse Boss 已启用、目标区块已加载，并且当前没有冲突事件。

## 6. 物资箱与刷怪笼维护

### 发放测试物资箱

```mcfunction
/scriptevent daily:crate give
```

此命令会发放多种测试箱和神话密钥，只用于管理员验收。

### 强制重扫刷怪笼

管理员站在目标刷怪笼附近执行：

```mcfunction
/scriptevent daily:crate scan
```

系统会重扫附近3×3区块，只检查：

- 地表上方6格、下方6格；
- 玩家上方6格、下方12格；
- 其他高度完全不扫描。

原版刷怪笼会替换为无品质废墟物资箱，刷怪笼内部保存的怪物种类不影响识别。执行后在附近停留数秒。

### 已探索旧地图补生成

原生 Feature 只影响首次生成的新区块。旧地图按以下流程补箱。

开启：

```mcfunction
/scriptevent daily:crate backfill on
```

查看状态：

```mcfunction
/scriptevent daily:crate backfill status
```

关闭：

```mcfunction
/scriptevent daily:crate backfill off
```

标准流程：

1. 在维护时段开启 `backfill on`。
2. 管理员沿旧地图主要道路、城市和玩家活动区移动，让区块重新加载。
3. 定期执行 `backfill status`，确认队列能够下降。
4. 检查箱子没有生成在基地、道路中央或异常位置。
5. 完成目标区域后执行 `backfill off`。
6. 再执行 `status`，确认显示“已关闭”。

注意事项：

- 候选密度固定为 `1/6`，长期平均约每4～8个区块一个。
- 区块内已有任何品质物资箱时不会再补。
- 只允许草方块、泥土、石头、沙地等自然表面。
- 检测到门、箱子、工作台、玻璃、木板、围栏等建筑特征时放弃该位置。
- 已处理候选跨重启保存，不会重复补生成。
- 开启状态也跨重启保存，完成后必须手动关闭。
- 开启期间不要前往新区块，避免原生 Feature 与补生成器同时参与生成。

### 物资箱刷新规则

- 废墟箱不分品质，可掉落原版杂物、Addon 食物、医疗品、弹药、半成品、Epic 图纸、神话密钥和金币。
- 金币为1～1000，金额越高概率越低，中位数约150。
- 打开后只切换为已搜刮状态，不删除方块。
- 冷却结束且附近没有玩家时恢复。
- 生存挖掘和爆炸无法破坏物资箱。

## 10. 保险箱规则与排障

- 保险箱只能从商城购买，默认每账号每日限购1个。
- 创建时设置4～8位数字密码；知道密码的玩家均可存取。
- 保险箱有2000点玩法耐久，当前所有近战与枪械伤害减免90%。
- 特殊枪械穿透白名单当前为空，仅保留配置占位。
- 容器实体使用高生命保护并持续恢复。
- 耐久归零后变为报废保险箱；密码失效，任何人均可打开。
- 报废后实体、入口和27格库存继续存在，但无法回收。
- 未报废且已清空的保险箱可由拥有者回收；重新放置恢复满耐久。

保险箱异常时：

1. 确认 SAPI 为 `2.10.0` 或更高版本。
2. 确认 SAPI 行为包和资源包版本一致。
3. 查看内容日志中的 `[Safe]` 错误。
4. 先确认是否只是资源包未加载，不要立即在原位置重复放置。
5. 记录拥有者、坐标、时间和使用武器，通过审计日志排查。

## 11. 更新、备份与回滚

更新前：停止服务器，完整备份世界、行为包和资源包，记录版本，并确认旧区块补生成器已经关闭。

更新后：

1. 同时更新 `.mcaddon` 中的行为包与资源包。
2. 不要同时启用相同 UUID 的新旧版本。
3. 进入世界等待初始化，再完成每日开服检查。
4. 验证金币、商店、奖池、日常、物资箱、副本、摸金都市和保险箱。

出现严重问题时停止服务器并恢复完整世界备份。不要只回滚行为包而继续使用已经被新版迁移的数据世界。

## 12. 源码构建

在仓库根目录执行：

```bash
bash daily_world_events_addon/build.sh
bash sapi_server_addon/build.sh
bash apocalypse_extraction_addon/build.sh
```

构建前运行对应目录的测试脚本，构建后确认 `.mcaddon` 压缩包可以正常打开，再部署到正式服务器。
