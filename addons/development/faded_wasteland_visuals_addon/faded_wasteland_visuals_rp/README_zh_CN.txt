余晖 · 废土光影 0.3.0（早期明日之后 · 多档亮度）

这是可导入的 Minecraft 基岩版灵动视效资源包。目标客户端：26.63；最低引擎声明 1.26.60。
需设备本身支持并能开启“灵动视效 / Vibrant Visuals”。

设计方向（参考 2018 年早期《明日之后》的末日废土观感）
- 阴天灰绿色调的日光：加大环境漫射光、压低直射太阳和天空亮度，受光面偏暖、阴影偏冷。
- 沙尘薄雾：全部地表群系的空气雾提前并加厚，远景发灰，天气雾更浓，强化空气透视。
- 低饱和、压抑但不发黑：整体去饱和、中间调略压暗、高光偏暖、阴影偏冷；刻意避免“泛绿泛黑”。
- 暖色人造光：火把/营火/灯笼/铜灯为暖橙色，灵魂灯/幽匿为冷青色，作为阴天与夜晚的亮点。
- 软阴影与浑水：软阴影风格；水面复用并重调（悬浮泥沙/叶绿素、焦散、波浪），呈现浑绿/浑黄的末世水质。
- 79 个原版地表生物群系分别绑定雾/大气/调色/光照/水面；下界、末地及洞穴类群系保留原版绑定。

不包含
- 不替换方块、枪械、生物、物品、UI 贴图（仅水面相关贴图与焦散贴图），不提供 MER/法线/粗糙度。
- 不改变伤害、弹道、怪物、天气频率，不含脚本，不含《明日之后》任何游戏资产（仅风格借鉴）。
- 不自带“按主城/周本/摸金区域切换”的功能（群系与服务器区域不是同一概念）。

0.3.0 多档亮度子包（解决正午/日落仍过亮）
- 在“资源包设置”里本包下方可切换子包（不同档位共享全部群系/雾/水面配置）：
  · 偏暗 · 早期废土（推荐，默认）：正午 24000 lux、天空 0.28、分级 gain 0.86
  · 标准 · 自然日光：正午 42000 lux、天空 0.40、分级 gain 0.92
  · 更暗 · 阴郁废土：正午 12000 lux、天空 0.20、分级 gain 0.80
  · 诊断档 · 极暗测试：正午 3000 lux、天空 0.10、分级 gain 0.55——**选它如果仍然很亮，
    说明当前加载的不是本包，或还有别的光影包覆盖在上方**（先停用其他光影/天空/雾包再测）。
- 为什么继续调 lux 可能没用：灵动视效有自动曝光，会抵消均匀的环境亮度变化；0.3.0 因此同时用
  色调映射后的 color grading gain / offset、天空强度、大气散射和雾吸收来压暗，这些不会被自动曝光完全抵消。
- 若使用服务器：服务器世界资源包列表必须指向本包 0.3.0（旧版本会继续下发旧画面）；
  在服务器 Packs 页更新/替换后，世界设置里的资源包版本也要刷新。

0.2.0 → 0.2.1 曝光 / 白平衡修复（重要）
- 根因：0.2.0 使用 generic 色调映射 + 较高天空强度，且雾只有散射没有吸收；在当前灵动视效里
  高动态范围没有做 filmic 压缩，白天会整体过曝发白。
- 修复：改用 Reinhard Luminance 色调映射（暗部细节保留、高光不糊），加入 6550K 白平衡；
  日光回落到柔和自然档（正午 48000 lux、日出日落 7000 lux），天空强度 0.45，环境补光 0.06 lux 冷灰。
- 白平衡：暖白光出（太阳 #FFF0DC）、冷色环境/阴影补光（#B6C2C4）、暗部偏冷、高光偏暖、饱和 0.88。
- 空气雾：fog_start 0.72、密度 0.0035，散射 0.012 + 吸收 0.0045（有吸收才不会雾成一片白）；
  天气雾 #7A7B73。
- 参考早期《明日之后》实机图校准：柔和暖阳、自然但略低的饱和、冷阴影、远景空气透视。

0.1.0 → 0.2.0 主要变化
- 日光：正午 95000 → 30000，日出日落 16000 → 6000；天空强度 0.92 → 0.58。
- 环境光：正午 0.06 → 0.12（阴天漫射），颜色改为灰绿 #B3BDB6。
- 大气：rayleigh 降低、太阳眩光/散射大幅降低；天空/地平线改为灰蓝、日出尘黄。
- 调色：中间调增益 0.92、饱和 0.82、暗部偏冷、高光偏暖，轻抬黑位。
- 雾：全部 67 个地表雾 og_start 提前到 0.55，空气雾密度 0.0035 → 0.0065，天气雾 0.012 → 0.02，雾色改为灰尘色系。
- 水面：新增 5 个水配置（temperate/desert/snowy/swamp/pale），绑定到 79 群系，含焦散贴图与浑水参数。
- 光照：新增本地光源配置（暖色火把/营火、冷色灵魂灯）与软阴影配置。

安装
1. 导入本 mcpack 并启用；在视频设置里选择“灵动视效”。不可用时检查设备/客户端支持，本包不能强制解锁。
2. 本包应放在其他天空/雾/光照资源包上方，不要同时叠多个光影包。
3. 服务器需把本包加入世界资源包列表并让客户端下载；客户端仍需自行开启灵动视效。
4. 恢复原样：停用本资源包即可。

调参建议（改完需要重新打包）
- 白天仍偏亮：lighting/global.json 的 sun.illuminance 正午键（0/1）与 sky.intensity（当前 0.58）。
- 白天太暗：提高环境光 ambient.illuminance（当前 0.12）而不是直接拉高太阳，避免失去阴天感。
- 雾太闷/能见度差：fogs 的 air.fog_start（当前 0.55）与 volumetric 空气密度（当前 0.0065）。
- 颜色太绿/太灰：color_grading 的 midtones.saturation（当前 0.82）与 gain。
- 水面太浑/太清：water/*.json 的 suspended_sediment 与 chlorophyll，焦散强度 power。
- 火把太艳：local_lighting/local_lighting.json 的 torch/campfire light_color。
