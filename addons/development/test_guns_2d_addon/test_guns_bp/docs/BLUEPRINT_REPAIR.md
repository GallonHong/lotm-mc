# 枪械专属蓝图修理

本次仅改变30把枪械的材料修理规则，保留原版 `minecraft:durability`、耐久数值、报废、耐久条、原版同类合并修理和现有武器ID。护甲、喷气背包、8件近战和2件盾牌的修理规则不变。

## 用法与数值

在铁砧左槽放受损枪械，右槽放对应型号的蓝图。每消耗1张蓝图恢复最大耐久的80%，不足1点向上取整；不超过最大耐久。恢复量按最大耐久计算，不是按当前损耗计算。当前30把枪的最大耐久均为5的倍数，80%恰好都是整数。右槽堆叠多张时，原版界面可按所需数量消耗多张。原版经验费用、铁砧工作惩罚及“过于昂贵”规则照常适用。蓝图是消耗材料，不是永久解锁凭证。

- AK-47：960；AK-74U：880；M870：640；M1897：600；Bizon：1040；Glock：560。
- SCAR-H：1120；ARX-160：1080；P90：1280；沙漠之鹰：520；SVD：480；M1014：720；RPK：1200；M79：64。
- PKM：1600；M1014「泰坦壁垒」：960；USAS-12：1200；RPG-7：120；M82：400。
- AK-47「指挥官」：1680；HK MP7：1440；MGL：360；特斯拉：720；DBSS：960；裂轨：720；百战：1600。
- SCAR-H「剥甲者」：1520；MP5K「接力者」：1360；Python「谢幕」：1120；喷火器：1440。

例如，最大耐久1800的喷火器每张修复1440点：剩余100点时变为1540点，剩余500点时回满1800点，不会得到超过上限的耐久。

对应物品通常为 `test_gun:blueprint_<枪械ID后缀>`，三处使用既有制造映射：

- `test_gun:shotgun` → `test_gun:blueprint_m870`
- `test_gun:vector` → `test_gun:blueprint_mp7`
- `test_gun:arc_emitter` → `test_gun:blueprint_arc`

新增 `test_gun:blueprint_baizhan`，既用于百战制造，也用于修理。蓝图本身不可合成；配套SAPI提供独立百战传说抽奖池，详见 `BAIZHAN.md`。仅启用Guns时没有SAPI抽奖入口，可通过创造物品栏或管理员命令提供蓝图，不额外增加怪物掉落。其余蓝图获取方式不变。

## 延迟磨损与兼容

喷火器与百战仍在连续射击时记账，停火后写回原物品，以免中断长按。修理前应先停火。欠账始终仍需结算，修理不会清除已发生的消耗。

这两把枪的新结算会把回执与耐久一起写入同一物品。若物品已经扣除磨损但账本清理失败，之后进行原版修理，重试通过回执确认已扣除，不再重复扣除或因耐久下降锁死。若物品写入尚未成功，修理后只补扣尚未落到物品的消耗。旧版没有回执且结果不明的异常事务仍保守停止，不猜测是否扣除成功。

未移除或替换原版耐久组件，已有物品不需要耐久迁移，包UUID不变。原版合并、重命名及附魔对物品动态属性的保存行为仍需要在实际目标游戏版本中验证；本次未以脚本模拟结果冒充游戏实测。

## 验证

- 30把枪的材料列表仅含各自蓝图，数值按80%向上取整，全部蓝图物品存在。
- 对照旧交付包，30把枪除 `minecraft:repairable` 外的定义完全相同；其他物品修理配置未变。
- 延迟磨损测试覆盖正常结算、修理前未结算、物品写入失败、清账失败、结果不明、重复修理周期、克隆隔离和最后一点报废，并以喷火器/百战的真实最大耐久及80%修复量模拟近报废修复、满耐久截断与未结算欠账。
- 实机待测：单张/多张蓝图消耗、错误型号拒绝、满耐久拒绝、铁砧费用、同类合并、百战/喷火器停火修理及物品动态属性保存。
