基线：GallonHong/lotm-mc `c3b70ef57281c6c2a355bbd44796b3c91f3926bc`。本次没有推送。三件武器使用原创生存工业风方块模型，参考废土工具、旧金属与战术装备的视觉语言，没有提取《明日之后》模型或贴图。

## 操作与获取

- 右键或触屏“使用”：一次普通攻击。每次松开再点击推进连段；连续按住不自动重复。4秒内未继续攻击，连段回到第一段。
- 潜行＋使用：一次重击。砍刀/重锤/长矛重击前摇分别0.65 / 0.85 / 0.55秒；前摇中换槽、换物、死亡、换维度或进入不可攻击比赛状态会取消伤害。
- 左键仍是原版基础推击，三件物品均设定0额外原版攻击伤害。完整连段、护甲暴击继承、范围判定与技能都在“使用键”链路。Script API 1.15没有稳定通用的原版左键伤害取消事件，不能把 afterEvents.entityHitEntity 当作可取消的攻击前事件来实现无重复扣血。
- 创造栏“装备”可以找到物品。也可使用 `/give @s test_gun:salvage_cleaver`、`/give @s test_gun:breach_hammer`、`/give @s test_gun:pulse_spear`。
- 工作台配方分别使用铁锭＋现有枪管零件＋木棍、铁锭＋活塞＋红石＋木棍、铁锭＋铜锭＋红石＋木棍；精确摆法见 `test_guns_bp/recipes/recipe_*.json`。
- 铁锭每次修复20%最大耐久。普通攻击消耗1点，重击3点，包括落空；群攻只消耗一次。尊重耐久附魔，创造模式不消耗。武器在最后一击用坏后只移除主手该物品，不改背包与比赛保管箱。

## 护甲、PVP与兼容

所有完整近战命中走现有 `DamageHandler.handleHit`。基础5%暴击率、1.5倍暴伤，以及头盔/胸甲等攻击增益沿用现有装备代码，没有维护一套容易失配的近战暴击表。不会额外触发枪械限定的专精，也没有近战爆头或距离衰减。目标护甲、盾牌、击退抗性、装备磨损沿用共享链路。割裂也走共享减伤链，禁用额外暴击，最多3跳且不叠加多个同目标出血计时器。

- 每次命中重新检查生命、队友、比赛、保护、倒地与裂轨眩晕状态。
- 前摇结束才取实际目标；按前向角度、三维距离、视线和最近目标数量上限过滤，不穿实心墙。
- 普通世界攻击玩家复用仓库已有 SAPI `tg:rail_guard` 一次性区域权限桥，收到可信服务器准入才造成伤害。拒绝、缺少 SAPI、20 tick超时、伪造来源、重复回应或目标跨禁止边界均不执行自定义玩家伤害。怪物和已参加比赛的目标分别沿用怪物/PVP标签路径。
- 割裂每一跳都重新检查团队、比赛和区域准入，不在换队、复活保护或退出比赛之后继续匿名扣血。
- 不覆写 `player.entity.json`，不修改全局玩家原型、玩家移动速度、相机、输入权限或第三方原始模型。仅在主脚本增加独立模块导入。
- 这些规则覆盖新增自定义使用攻击，不能替代服务器对所有原版拳击/原版武器的统一保护。

## 参考附件与直接代码复用

用户提供：`炽热战斗(战斗机制重置).mcaddon`。内部包标识为 Fiery Combat Add-on 1.0，描述署名 **fieryabyss**，汉化标注“b站男巫”。附件SHA-256：`44cdcf5fcf13bb9cbb24b19d3999f5567f6a29fd94bce56e73487c29394270de`。

参考包要求 Bedrock 1.26.50、`@minecraft/server` 2.10.0，且资源使用优化 brarchive，主脚本混淆。现项目仍使用 Script API 1.15.0，所以没有把整包脚本导入，也没有引入新API、参考包的玩家动画全局接管、相机或原型修改。

`test_guns_bp/scripts/vendor/fieryCombatCore.js` 原样保留四个所需代码片段：

1. `_0x10033` → 导出 `facingAngle`：面对目标的水平夹角。
2. `_0x10112` → `createComboAttack`：普攻连段描述和实际命中tick。
3. `_0x10113` → `createHeavyAttack`：单次重击描述和实际命中tick。
4. `_0x10117` → `ComboTracker`：连段索引、记录、重置和80 tick连段窗口。

原函数体与原变量名不改，仅在外层补原本的 `system10` 导入、80 tick常量和易读导出。来源偏移、脚本摘要和片段摘要写在 `fiery_combat_provenance.json`；自动测试逐一校验摘要，证明这部分是直接复用而非仅模仿。其余适配、武器数据、模型与测试是此次新增。
