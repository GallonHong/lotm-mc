# 移除原版生物蓝图掉落

适用版本：Guns 3.16.11 / SAPI 2.14.14。

## 原因与修改

旧版 `scripts/main.js` 的全局 `entityDie` 回调会调用两个额外掉落模块：

- `EpicBlueprintLoot.onDeath` → `EPIC_BLUEPRINT_DROPS`：玩家击杀掠夺兽时12%掉落 `test_gun:blueprint_scarh_stripper`；击杀唤魔者（`minecraft:evocation_illager`）时10%掉落 `test_gun:blueprint_python_finale`。
- `FlamethrowerBlueprintLoot.onDeath`：玩家击杀烈焰人时8%掉落 `test_gun:blueprint_flamethrower`。
- 两个模块原先均排除PvP参与者，并直接在死者位置 `spawnItem`。它们不依赖怪物战利品表，也不要求玩家使用对应枪械击杀。

现已删除两个模块、入口导入和死亡回调调用；删除Guns及SAPI伤害模块副本中的旧掉落映射。SAPI原先只有该映射副本，没有注册这两个掉落模块。没有以概率归零、PvP标签或全局地面物品清理替代删除。

## 保留范围与影响

- 原版怪物自身战利品不变。Guns没有战利品表覆盖；SAPI唯一战利品表为既有空表，本次未改。
- 蓝图物品、已有背包/容器中的蓝图、成枪配方、80%蓝图修理和其他蓝图配方不变。
- SAPI抽奖、保底和商人配置不变，百战、裂轨等奖池继续保留。
- 不修改第三方箱子、活动、自定义怪物掉落，也不拦截其他包生成的物品。本次两包中未发现独立的自定义怪物蓝图掉落源。
- **SCAR剥离者、Python谢幕和喷火器这三张蓝图在检查的Guns/SAPI两包中没有已确认的其他生存获取渠道。** 它们仍可通过创造或管理员提供。本次没有擅自新增替代配方或奖池；其他已安装包是否提供它们须另行核实。

## 联机与验证范围

删除的是服务端共享的死亡事件处理，适用于各玩家、各维度和各击杀方式，不依赖击杀者标签或概率。保留同一回调中的护甲/开火状态清理、史诗武器死亡判定与火焰/PKM/百战状态清理，不影响玩家死亡物品规则。

模拟测试运行真实 `main.js` 事件注册，覆盖原三种怪物、其他原版实体、自定义实体、玩家死亡、不同击杀者/PvP标签/维度、重复与交错死亡事件。其余模块为记录调用的替身，不能代替Bedrock联机实机测试。独立发行审计与旧3.16.10/2.14.13包比较，证明只从死亡回调删除两项掉落调用，所有蓝图物品、配方、抽奖/商人、实体和原有战利品表未改。

更新后需重新加载世界/服务器使旧脚本停止。实机待验：服务器及两名玩家使用新包，分别击杀掠夺兽、唤魔者、烈焰人，确认无本包附加蓝图；检查普通战利品、已有蓝图修理、抽奖与玩家死亡流程。若仍有蓝图掉落，应检查其他启用包或未重载的旧脚本，不能据此认定本次代码已在该世界生效。
