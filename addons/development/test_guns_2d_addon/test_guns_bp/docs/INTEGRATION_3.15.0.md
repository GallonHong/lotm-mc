# Test Guns 3.15.0 完整整合测试版

本版包含此前3.14.0全部改动以及百战、三把史诗枪、喷气背包视觉更新与本次资源修复。只有一个Guns BP/RP整合包，不需要叠加任何本轮中间Guns包。原包UUID保留。未推送仓库，未公开发布。

## 本次新增

- **百战**：传说重机枪，基础单发27，弹仓100；潜行架枪、松开/切枪退出，手持与架枪射速不同，随机普通/爆炸/燃烧/减速/穿甲弹。架枪最多穿透两层明确允许的软方块，对指定车辆和无人机增伤。无额外实体武器可拾取复制。逐发逻辑磨损持久记账，停火后结算原物品。
- **SCAR-H「剥甲者」**：史诗，伤害18，同一目标连续有效命中的穿甲由45%逐次升至80%，失误、换目标、换枪或超时重置。
- **MP5K「接力者」**：史诗，伤害13.5，确认直接击杀回复2至4发弹仓弹药，不生成背包弹药；PvP只改比赛弹仓。
- **Python「谢幕」**：史诗，伤害9，命中前生命不高于35%的目标受到1.75倍伤害，六发半自动。本历史版本曾给两把史诗蓝图加入掠夺兽12%/唤魔者10%实际玩家击杀掉落；该原版生物掉落渠道已在3.16.11删除。MP5蓝图可制造，三枪制造仍消耗各自图纸。
- **喷气背包视觉**：原创废土机体、离子喷口/火星/短烟，保持8护甲、暴击+10个百分点和共享伤害+12%等既有战斗数据。
- **图标与动作引用**：逐一检查29张真实物品图标，枪口全部朝左上。修复百战方向、三史诗不透明底板、6把枪缺失的附魔材质别名，以及新4枪在玩家持握分类中的遗漏。
- **SAPI联动**：补齐裂轨及新增枪的PvP托管名单；29枪登记一致。百战改为SAPI同一回调内重新核对当前区域、射手/目标、队伍与几何路径后同步施伤，不在延迟回执后再次施伤。旧百战授权协议停用，缺失/混用旧伴随包时拒绝百战伤害。
- **百战保护限制**：本版百战不对普通世界玩家造成直击、溅射或持续燃烧伤害；在SAPI正式PvP比赛中仍可按比赛规则伤害敌方玩家，对怪物/载具功能保留。原因是当前Life没有可靠的反向动态安全区授权桥，采用保守拒绝，不声称已覆盖外部包私有区域。普通玩家对持重装反甲盾的怪物也拒绝该次百战命中，避免盾反绕过限制；正式PvP反甲保留。此限制不改变其他枪械。

裂轨25/50/80及机械蓄力音/火星/短烟/短弹道；三件近战与共用伤害链；PKM逐跳燃烧与第三跳爆燃；两盾持握修复；按单发及品质倍率的枪械/制造平衡；M79换弹23 tick、MGL换弹35 tick；7把传说武器物品栏仅显示枪名。详见相应docs文档。

## 安装与版本

1. **先备份世界。** 退出世界后导入并启用 Test Guns 3.15.0 BP/RP与服务器核心SAPI 2.14.5 BP/RP。两者需要配套升级；不要同时启用各自旧包或本轮中间包。
2. 原本启用了“末日生存 + Guns姿态兼容”时，使用本次1.1.2替换1.1.1，资源优先级继续置于Life和Guns上方。它只扩展新4枪持握判断，保留旧玩家映射。没有使用此兼容包的世界不必额外启用。
3. 保留Life、Boss和其他既有伴随包，不要用本次包替换它们。SAPI 2.14.5以原2.14.4为基线，原文件除明确的版本、集成入口和枪械名单改动外保持原字节。
4. 同UUID缓存导致版本不更新时，在备份后从“设置→存储”移除旧对应包再导入。不要删除世界。进入世界检查Guns3.15.0、SAPI2.14.5与可选兼容1.1.2。
5. Guns最低引擎1.21.60，Script API依赖仍为server1.15.0/server-ui1.3.0。文件不包含对运行游戏的测试证明。
