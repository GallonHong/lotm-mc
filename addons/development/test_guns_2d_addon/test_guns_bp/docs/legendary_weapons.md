# 传说枪械名称与操作

物品栏名称仅保留枪械名；品质、技能和数值不再拼接到名称中。传说级以 `scripts/data/guns.js` 的 `tier: 'legendary'` 为准：AK-47 战术指挥官、HK MP7、MGL 40mm、特斯拉电弧发射器、DBSS 裁决者、裂轨。PKM 是史诗级，图纸、防具和喷气背包不在这次枪械名称调整范围内。

裂轨操作说明（从原物品名移至此处，战斗 HUD 仍显示实时蓄力与弹药）：
- 四发弹仓，使用高能电池。
- 长按使用蓄力，松开击发。
- 三级直击伤害为 45 / 90 / 150，溅射基数为 36 / 72 / 120，半径为 3.5 / 5.5 / 7.5 格。
- 溅射与中/满蓄减速按爆点周围的三维球体判定，上下方无遮挡敌人同样有效；墙体和实心楼板仍会阻挡。
- 直击目标只结算一次，其余范围目标独立结算。中蓄减速 III 持续 3 秒，满蓄减速 IV 持续 4 秒。
- 潜行使用发动裂空音波：72 基础伤害，36 格射程、2.8 格半径，最多 18 个目标，眩晕 1.8 秒，冷却 30 秒。

以上为护甲和盾牌减伤前数值；其余枪械技能与数值由武器配置及 HUD 提供。
