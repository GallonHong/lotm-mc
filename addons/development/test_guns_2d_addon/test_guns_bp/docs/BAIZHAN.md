# 百战：传说重机枪（独立增量）

本改动基于待发送的 Test Guns 3.14.0 完整副本，保留此前裂轨、三近战、喷气背包、两盾、PKM燃烧、枪伤与配方、M79/MGL换弹改动。没有修改原整合目录，没有上传、提交或推送。最终发布版本号交给统一整合步骤设置。

**当前保守限制：百战对普通世界玩家的直接、溅射、燃烧伤害均关闭。合法PVP比赛伤害及怪物、载具/无人机战斗保留。Life 1.4.5的私有动态安全区没有可靠跨包查询桥，因此不猜测普通世界玩家的伤害权限。**

## 操作与数值

- 物品 ID：`test_gun:baizhan`，物品栏标题仅“百战”，传说品质，机枪分类。
- 使用已有 `test_gun:ammo_belt_100`，没有增加新弹种。
- 手持：100发弹仓，首次生存领取从空仓开始，左键换弹4秒；射速每4 tick一发（5发/秒）。
- 潜行自动架枪，1秒完成。玩家继续保持潜行，右键/长按右键手动射击，不自动索敌、不自动开火。
- 架枪：每3 tick一发（约6.67发/秒），直接从背包消耗1个现有弹药物品，不消耗手持弹仓、不换弹。
- 取消潜行收枪；架设点移动超过0.45格、切枪/切槽、死亡、掉线、跨维度、比赛状态变化都会停火并清理展示实体。移位后需先起身再潜行重新架设。
- 枪始终保留在原物品栏，不转存实体。回收只删除展示物，不返还/复制枪或弹药。没有多个展示实体循环回收刷弹的路径。
- 耐久每发先登记到持久化物品欠账，连发中不写回手持装备；松手/切枪/收枪时仅结算相同物品ID。原物品已丢弃时保留欠账，下次任意玩家拾取先结算；PVP副本与生存原件分账，清账中断使用写前记录避免重扣。逻辑耐久归零立即停火/破损，不能靠换枪、换槽或重登免耗。
- 长按最长连续10秒，之后需松开重按。这是丢失松手事件的停火保护。
- 基础单发27、射程80格、基础护甲穿透42%、爆头1.5倍、每格衰减0.8%，沿用共享防具/装备/暴击/盾牌结算。
- 每一发随机：普通50%，溅射15%，燃烧10%，缓慢10%，穿甲15%；两模式使用同样概率。
- 溅射：2.5格，旁目标最高10基础伤害随距离衰减；不重复给直接命中目标加同帧溅射，不破坏方块。
- 燃烧：命中被接受后每秒3基础伤害、持续3秒，同一射手续时不叠层；水、抗火、切枪和来源状态变化终止。每跳保留射手归属并重新校验，不调用原版无归属点燃。
- 缓慢：命中被接受后施加缓慢II，2秒。
- 穿甲弹：该发护甲穿透85%；手持不会因此穿墙。
- 架枪最多穿透2个白名单软掩体方块：玻璃/玻璃板、木板/原木/树叶、羊毛、泥土/沙/沙砾等。第三格、石头、金属、门、容器、基岩、屏障、液体、未知区块全部挡住。白名单是明确枚举，不破坏任何方块。
- 两模式对已知Life五种载具和19种无人机的直接、溅射、燃烧基础伤害统一×2，再走原共享护甲链。没有按模糊字符串给其他实体加倍；无人机弹丸和辅助效果实体不计入。

## 弹链箱历史问题，未做破坏性转换

现有物品名写“100发”，但现有 count/consume/reload 代码一直按“1物品=1发”运作。本改动保留该物品ID、名称、堆叠、配方和旧枪语义，百战也按实际1:1消耗，不把已有存量放大100倍。

若以后希望真正一箱100发，需要单独制定版本化迁移与剩余发数存储、旧弹链迁移标记、半箱合并/丢弃、箱内余弹与PVP托管；不能只把count乘100而consume仍按物品扣除。此版本没有暗改或执行这类转换。

## SAPI必须一起升级

独立伴随改动从已验证的 SAPI 2.14.4 原包制作。安全增量使用 `tg:baizhan_hit` / `tg:baizhan_hit_result`；旧 `baizhan_guard` 协议已停用，混用旧版会安全拒绝伤害。

- SAPI 在同一个同步回调中读取当前安全规则、验证完整路径，然后立即调用与最终Guns逐文件一致的伤害闭包。没有“先批准、回包后由Guns施伤”的时间窗口；管理员在请求排队期间修改SAPI自身可读取的区域、地皮或出生点，会按最新状态拒绝实际伤害。外部Life私有动态区域不在该读取范围，普通世界玩家因此统一拒伤。
- 伤害闭包从最终整合版原样镜像，完整保留装备加成、暴击、爆头、护甲、防暴盾、同步反甲、装备磨损和射手归属，不调用匿名伤害或原始生命值兜底。每次更新共享伤害公式需要同步镜像，并跑逐文件一致性检查。
- 每次直接/溅射/燃烧都是服务器来源的一次性限时请求。验证来源、nonce、12tick有效期、共享lore中的唯一BAIZHAN_ID、物品槽、单一公开会话epoch、双方队伍/比赛/末日倒地状态与潜行模式。Guns私有ItemStack动态属性仅用于自身欠账，SAPI不跨命名空间读取；缺失私有ID时复用已有共享身份偿还旧欠账，不创建新ID逃耐久。玩家命令、命令方块、过期或重复数据被拒绝。
- 检查射手到枪口、完整弹道、溅射父路径和次级路径、目标身体，覆盖SAPI可读的管理员区域、本地保护配置、出生点圆形保护和领地安全区。按精确分段检查薄区域，不宣称读取了Life的私有动态属性。
- 新持枪状态、部署、收回会更替单一会话epoch；切枪/清理移除旧epoch。已排队的旧请求即使随后换回同枪同槽也不能继续施伤。离线时间戳另外拒绝快速重连时的旧请求。
- 缓慢与伤害在同一个SAPI回调完成。Guns收到的仅是已执行结果，用来显示反馈或开启后续燃烧计时；不会再次造成伤害、反甲、缓慢或防具磨损。每跳燃烧仍重新发送完整权威命中请求。
- PVP百战加入特殊枪械托管名单；架枪比赛备弹无限，不消耗生存背包。手持比赛弹仓与生存弹仓保持独立。
- 耐久新增服务器权威 `baizhan_wear_state` 协议，读取现有单场PVP管理器的当前match ID。仅清理已不再活跃的比赛副本欠账，永不清理生存原件欠账；每把枪最多保留生存+当前比赛2个scope，写入硬上限4096字节。旧比赛标记物品不能在普通环境或其他比赛使用，清理失败的比赛仍保留原ID与欠账。初始化枪描述时保留PVP回收标记。
- 武器耐久写入返回false、静默未写入、或读回不是原标识/足够耐久损伤时，不会清除欠账。破损必须确认原槽物品实际移除；中断后的写前记录防止重复扣除。
- 所提供的SAPI没有独立通用反穿墙射线钩子；没有创建通用反作弊绕过。另装第三方反穿墙插件时仍需真实接口适配。
