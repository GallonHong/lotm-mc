# 枪械单发伤害与合成平衡

后续独立请求已将 M79 换弹从45调整为23 tick（2.25→1.15秒），MGL从70调整为35 tick（3.5→1.75秒）；本报告中“换弹不变”仅描述伤害/配方平衡本身，不包含这两项后续专项。详见 M79_RELOAD.md 和 MGL_RELOAD.md；测试仅为二者保留精确的半时长向上取整例外，其他非伤害属性仍严格比较。

## 范围与口径

- 以集成版 3.14.0 当前内容为基线，只改 `scripts/data/guns.js` 的指定伤害字段、13 个配方和验证/说明文件。未改版本号、模型、材质、物品 ID、库存、名称或存档。
- 普通 Glock 保持 4.5；普通冲锋枪取 1.5 倍即 6.75，普通突击步枪取 2 倍即 9。常规枪械稀有/史诗/传说系数取 1.5/2/3，不使用 DPS 反推伤害或削弱射速。
- 同品质同大类统一基础伤害，保留弹容量、射速、换弹、后坐力、射程、衰减、穿甲、爆头与所有专属被动，因此 AK-47 与 AK-74U、SCAR-H 与 ARX 等仍有实际手感/距离差异。
- 霰弹按**每颗弹丸**计值，现有所有霰弹武器每次击发发射 8 粒。普通 3，稀有 4.5，史诗 6，传说 9；理论整发合计 24/36/48/72，不把单粒伤害冒充整发。此值不代表散射中必然全中，也未含距离、护甲、暴击与技能。
- 机枪当前使用 `type: rifle`，不更改分类字段以免改变装备联动。RPK/PKM 的基础伤害按步枪口径分别取 13.5/18，压制与燃烧仍由既有逻辑单独结算。
- Deagle 是 .50 重手炮，保留 25；SVD/M82 是不同重狙，保留 45/75；RPG 保留直击 100、溅射 80。这些没有普通同构版本，未强行套轻型手枪比例。
- MGL 与 M79 是同种 40mm 榴弹发射器。最低现有 M79 虽为稀有，仍作为同类低品质基准：MGL 直击 84=28×3、溅射峰值 90=30×3，爆炸半径、榴弹轨迹、友伤保护与饱和轰炸不变。直击目标在既有实现中不再吃这次溅射，不能把 84+90 当成单体伤害。
- 电弧与裂轨虽都标记 `energy`，分别是连锁电击和多级蓄力炮，不能作为同一种武器互相相乘。没有低品质同构版本，保留电弧 16 与裂轨 25/50/80 蓄力档及溅射 0/8/12。没有虚造低级能量枪。
- 伤害单位为现有脚本 HP（2 HP=1颗心），比例指衰减/护甲/暴击前基础伤害。既有结算保留 0.1 HP 四舍五入，例如 Bizon 6.75→近距无甲6.8，MP7 20.25→20.3，最终显示数值可能不是精确3倍。

## 材料获取与限定门槛审计

- 枪管：2铁锭+1铁粒；机匣：2铁锭+红石+拉杆+平滑石；枪托：2木板+煤+2铁粒；弹鼓：3铁锭+铜锭+拉杆。上述公共配方不变。

- `part_tungsten_bolt`、`part_military_fcu`、`part_ion_thruster`、`part_plasma_core` 在本包均有物品定义但没有合成配方。检查配套 Apocalypse Mobs v0.7.1 包的 Boss 掉落：突变骷髅有钨合金机心，突变投掷者有火控核心，警笛头有离子推进器/等离子核心，雾人和突变铁傀儡有等离子核心。没有改这些掉落。
- 在本地恢复的 Daily Events 代码样本 `daily_events_bp/scripts/rewards/lootCratePools.js` 中，神话箱包含 PKM、USAS-12、M1014壁垒图纸和电弧图纸，并需神话密钥；零件池也含上述核心。该样本证明有联动渠道，不代表当前服务器已安装启用此版本。
- 其余传奇（指挥官、MP7、MGL、DBSS、裂轨）图纸在本包中存在且被成枪配方强制要求，但没有本包合成或掉落入口；本次检查的上述掉落样本也未证明它们的当前生存获取渠道。继续保留原有管理员/活动投放门槛，不擅自增加获取方式。单独安装 Test Guns 时，限定图纸/稀有核心并不能保证自然获得。
- 验证了153条配方的描述ID唯一、表格尺寸、键位、所有自定义输入/输出物品ID存在、25把枪各自图纸必需、成品数量1和递归成本图无循环。明确禁止为9种限定枪图纸恢复配方。原版材料命名沿用既有已使用的 Bedrock ID，没有引入新命名空间。

## 既有系统的影响与保留

- 射速不改，因此单发提高的枪持续火力也会上升，低级步枪则下降。这是按用户单发比例要求实施，未尝试把各枪 DPS 拉平。基础5%暴击、各自爆头倍率、穿甲保底、距离衰减及护甲减免不变。
- PKM直击14→18；10格无甲非暴击直击11.9→15.3。燃烧仍为4秒、每0.5秒2HP、第3跳额外8HP，单次完整燃烧合计24HP；重复命中刷新而非叠成多条，SAPI每跳审批与成功直击才点燃的条件不变。
- 壁垒仍由自身护甲每点+3%、最多+100%增伤。20护甲时整发基础48×1.6=76.8，可能超过裸装DBSS的72；这是装备被动差异，不是基础品质倍率异常。
- USAS吸血比例仍18%，实际吸血量仍随实际伤害变化；DBSS锁敌龙息、MGL饱和轰炸、AK指挥官空袭、MP7暴走、狙击特效等逻辑均未改。
- 喷气背包+12%伤害/+10个百分点暴击不变；新近战共享DamageHandler、玩家/SAPI保护、队友过滤、装备耐久与承伤流程不变。未改运行时伤害处理代码。
