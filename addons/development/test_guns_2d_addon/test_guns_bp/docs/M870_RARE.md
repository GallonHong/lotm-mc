# 雷明顿 M870 蓝色品质调整

## 当前规格

- 实际物品 ID 保持 `test_gun:shotgun`，图纸保持 `test_gun:blueprint_m870`，旧存档与后续升级配方继续识别。
- 品质从普通改为 `rare`；枪械与图纸显示蓝色 `§9[优良]`，与既有蓝色 M1014 一致，图纸改用既有稀有图标。
- 每颗弹丸基础伤害由 3 改为 4.5，仍为每次击发8颗，理论全中基础合计由24改为36 HP。距离衰减、护甲、爆头、暴击和实际命中粒数仍影响最终伤害。
- 保留泵动操作与原有8发弹匣、16 tick 射击间隔、60 tick 换弹、后坐力、穿甲、射程、击退、800耐久与每张图纸修理640耐久。没有额外增加技能。
- GUNS 数组顺序不变，避免原有视觉索引错位。温彻斯特 M1897 仍是普通霰弹枪，3 HP/粒、8粒理论24 HP，所有属性和配方不变。

## 合成与升级

图纸仍可在工作台合成，每次产出1张：空白军用图纸×1、橡木板×1、铁块×1、金粒×1。取代原来“空白图纸+橡木板+铁粒”的普通档材料。

成枪每次消耗对应图纸×1、重型枪管×1、机匣×1、枪托×1、铁锭×2、霰弹×1，产出1把 M870。工作台位置：

```text
图纸  重型枪管  铁锭
机匣  铁锭      霰弹
空    枪托      空
```

以上自定义材料均可在 Guns 本包递归合成，不依赖 SAPI、Boss 核心、限定图纸或管理员投放。重型枪管和铁块提高蓝色档门槛；相较同为蓝色的半自动 M1014，保留较低的制造成本，不需要其额外弹鼓与两块铁块。

旧 M870→USAS-12、M870→DBSS 的升级配方仍消耗原物品 ID，各自限定图纸要求不变。M870 新成本随之传递到这两条升级路线；没有降低或移除限定门槛。
