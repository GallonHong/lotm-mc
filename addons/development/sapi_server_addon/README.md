# SAPI Server Addon

独立的 Minecraft Bedrock 服务器基础系统，源码、测试、构建脚本和安装包全部位于本目录，不再与 LOTM Pathways 源码混放。v2.11.4 修复玩家实体贩卖机物品图标错误、旧版 Script API 下无法注册部署/交互组件，以及模型显示链不稳定的问题。v2.11.3 在生活与载具商加入 20,000 金币、不可回收的钢琴商品；未安装 Apocalypse Life 时发放会安全失败且不会扣款。v2.11.2 修复通缉值衰减方法缺失结束括号导致整个 SAPI 模块无法加载、指南针菜单失效的问题；v2.11.1 将联盟保险改为返还贩卖机遇袭时实际丢失的库存；v2.11.0 增加玩家实体贩卖机、公会频道、队伍友军保护及通缉/保释/服务器黑名单。

## 目录

- `sapi_server_bp/`：可直接作为开发行为包使用的完整源码；
- `tests/validate_server.mjs`：菜单、抽奖、传送、签到、兑换码和版本验证；
- `build.sh`：独立构建入口；
- `SAPI_Server_BP.mcpack`：行为包；
- `SAPI_Server_Addon.mcaddon`：推荐导入的安装包。

## 构建与验证

```bash
node addons/development/sapi_server_addon/tests/validate_server.mjs
bash addons/development/sapi_server_addon/build.sh
```

主要配置位于 `sapi_server_bp/scripts/config.js`；奖池位于 `scripts/data/lotteryPools.js`；商店与回收价位于 `scripts/data/merchantConfig.js`；社交持久化位于 `scripts/data/socialStore.js`，菜单和关系逻辑位于 `scripts/modules/social.js`。SAPI Server 可独立安装，也可通过动态属性和 `scriptevent` 与 LOTM Pathways、Apocalypse Mobs、Daily & World Events 联动。

## 社交 MVP

- 好友和公会写入世界动态属性，玩家离线和服务器重启后仍保留；好友上限 50。
- 队伍仅存在于服务器本次运行内，最多 4 人，重启自动解散；队伍邀请、聊天、移交队长和移除成员全部从社交菜单进入。
- 玩家资料卡只公开名称、公会、称号、在线/所在状态和通缉状态，不公开坐标、金币、背包和装备。
- 好友观光必须由领地主人在地皮菜单设置访客点。邀请只执行传送，不把访客加入领地成员，也不授予破坏、放置、容器、保险箱或载具权限。
- 公会只有 `Leader` 和 `Member` 两级；Leader 可处理申请、邀请/移除成员、移交会长、编辑简介和设置基地。
- 公会页面内置最近 20 条公会频道消息；只有本公会成员在线时会收到即时广播。
- SAPI 单独安装时社交、好友、队伍和公会照常使用；只有“全队副本 Ready”需要启用 Daily & World Events。

## 玩家实体贩卖机与通缉

- 全球商店售价 15,000 金币、不可合成；每名玩家最多部署 2 台，主城/安全区部署另收 5,000 金币经营费，可自定义店名并上架最多 9 类背包物品。
- 成交不收手续费，营业额留在机器内，店主必须回到机器 4 格内手动领取；实体店商品不会进入玩家寄卖行的全服搜索。
- 机器挖掘时间为 100 秒（约两块黑曜石）。被破坏时只随机掉出库存中的 1 件商品，其余库存和未领取营业额永久损失；破坏者增加 50 通缉值。
- 店主可以为单台机器购买 10,000 金币的联盟保险。机器被破坏后，现场随机掉出的 1 件商品不重复赔付，其余库存原物返还；机器本体和未领取营业额不赔。背包空间不足的返还物会持久保管，之后重新进入世界继续领取。
- 方块外观复用仓库内 `Random plantsnblocks` 的 `vendmach` 模型与贴图；脚本、库存和交易数据仍全部由 SAPI 管理，未修改原素材包。
- 安全区攻击玩家每次增加 3 点、法制区增加 2 点（同一目标每秒最多计一次），保护区击杀额外增加 10 点；在线每 10 分钟降低 1 点。通缉值达到 20 后不能使用全球商店或管理自己的实体店，但仍可购买其他玩家实体店商品。
- 保释费用为 `max(60,000, 通缉值 × 3,000)`。管理员可单独清零、加入/移出黑名单，或一键将通缉值达到 50 的玩家加入服务器黑名单。
