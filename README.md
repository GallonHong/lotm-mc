# 🌟 Minecraft 基岩版 SAPI 综合管理系统 Add-on

本行为包 (Behavior Pack) 基于 Minecraft 基岩版最新的 **Script API (SAPI)** 开发，集成 **经济系统**、**分类商店**、**地皮领地保护** 与 **幸运抽奖** 四大核心功能，拥有原生 GUI 视窗交互与高性能数据持久化支持。

---

## 📌 功能概览

### 1. 💰 经济系统 (Economy)
- **原生计分板绑定**：货币绑定原版 `money` 计分板，完全兼容原版命令与侧边栏显示。
- **玩家安全转账**：图形化选择在线玩家，支持自定义转账金额与防作弊检查。
- **财富排行榜**：实时查看服务器前 10 名富豪榜单与个人资产。
- **初始启动金**：新玩家进服自动赠送初始金币（默认 1000 金币）。

### 2. 🛒 分类商店系统 (Shop)
- **多分类商城**：建筑方块、矿石资源、农牧食物、战斗装备、珍品专区。
- **双向交易支持**：
  - 🟢 **购买**：选择商品及购买数量 (1~64)，自动扣除金币并发放物品。
  - 🔴 **回收出售**：支持玩家出售多余建材、矿物与战利品换取金币。

### 3. 🛡️ 地皮领地保护系统 (Land Protection)
- **区块级地皮体系**：以 16×16 区块为单位认领专属地皮。
- **全方位防熊防爆**：
  - 🚫 拦截非信任玩家破坏方块 (`playerBreakBlock`)
  - 🚫 拦截非信任玩家放置方块 (`playerPlaceBlock`)
  - 🚫 拦截打开箱子、木桶、潜影盒、熔炉、漏斗、门、拉杆等设施
  - 🚫 爆炸保护：自动拦截苦力怕、TNT 等爆炸摧毁领地方块
  - 🚫 拦截触碰展示框与盔甲架
- **领地管理功能**：
  - 👥 **信任成员**：可添加或移除好友共建权限。
  - ⚙️ **权限细分**：可单独开启/关闭访客破坏、放置、开箱或爆炸权限。
  - 🚀 **领地列表与传送**：一键传送至自己拥有的任一地皮。
  - 👁️ **边界粒子高亮**：沿 16×16 区块边界生成显眼绿色粒子。
  - 💰 **地皮回收出售**：支持按 70% 比例返还金币。

### 4. 🎁 幸运抽奖系统 (Lottery / Gacha)
- **多等级奖池**：
  - 🪙 **普通金币奖池**：抽取日常实用建材、矿物与高性价比食物。
  - 👑 **高级欧皇奖池**：抽取限定神话枪械【雷霆聚能炮】、下界合金锭、不死图腾、附魔金苹果、潜影盒、鞘翅与下界之星！
- **单抽与十连抽**：支持 1 次抽取与 10 连特惠抽取。
- **欧皇全服广播**：抽中【史诗】、【传说】与【神话限定】奖品时触发全服跑马灯公告。
- **防爆仓机制**：背包满时自动将掉落物安全生成在玩家脚下。

### 5. ⚡ 抽奖限定武器：【雷霆聚能炮】(Thunder Blaster)
- **获取途径**：仅在【高级欧皇奖池】极低概率（神话品质）抽取，或管理员面板直接发放。
- **武器特性**：
  - 💥 **超强杀伤**：瞬发造成 **35 点高额聚能伤害**。
  - 🎯 **超远射程**：**50 格** 射线瞬发打击，附带强力击退。
  - ⚡ **炫酷特效**：发射贯穿视角的雷霆闪电光束，命中发生聚能粒子爆炸与专属充能音效。
  - 🔄 **手持长按/右键**：0.4 秒疾速连发射击，无限能量弹药！

### 6. 🧭 便捷交互与管理员控制台
- **多种唤起方式**：
  - 🎯 手持 **罗盘** (`minecraft:compass`) 右键直接弹出菜单。
  - 💬 聊天栏输入指令：`!menu`, `!shop`, `!land`, `!lottery`, `!pay`, `!money`。
  - ⚡ 运行命令：`/scriptevent system:menu`。
- **管理员面板 (OP/Admin)**：
### 7. 🔮 《诡秘之主》7大途径序列7与7大高阶封印物体系 (Lord of the Mysteries)

## 🛠️ 安装与使用指南

1. 双击运行导出的 `SAPI_System.mcaddon`，Minecraft 基岩版将自动导入行为包与资源包。
2. 创建或编辑世界，在 **行为包** 和 **资源包** 中同时激活 `SAPI_System`。
3. 确保世界设置中的 **Beta API（测试版 API）** 选项已开启。
4. 进入世界后，手持罗盘右键或输入 `!menu` 即可畅享全部系统！

### 赋予管理员权限
在游戏聊天栏执行以下指令赋予自己管理权限：
```mcfunction
/tag @s add admin
```
或直接通过控制台给予 OP 权限。

## ⚙️ 自定义配置指南

所有商品、价格、抽奖掉落、地皮单价均可在 [scripts/config.js](scripts/config.js) 中轻松修改：
- **修改货币名称**：`Config.economy.currencyName`
- **修改地皮价格**：`Config.land.pricePerChunk`
- **新增商店商品**：在 `Config.shop.categories` 的 `items` 数组中添加物品 ID、名称与买卖价格。
- **自定义抽奖奖品与权重**：在 `Config.lottery.pools` 中增减物品与配置 `weight`。
