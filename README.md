# 🌟 Minecraft 基岩版 SAPI Server + LOTM Pathways

服务器部署、管理员命令、旧地图补箱与故障处理见 [服务器运营手册](docs/服务器运营手册.md)。

项目已拆分为两个可独立启用、同时安装时自动联动的 Add-on：

- **SAPI Server Economy 2.9.2**：经济、分级商店、密码保险箱、地皮、寄卖行、免费传送、Home、可管理 TPA、每日签到、兑换码、主城保护与审计；七日签到每周期发放 28000 金币，安全区禁止创建领地，保险箱使用独立 2000 耐久和不可死亡的高生命容器实体。
- **LOTM Pathways 1.4.0**：途径、序列、魔药、能力、非凡媒介、封印物及全部对应资源。

两个包之间只通过心跳动态属性与 `scriptevent` 公共接口通讯，不互相导入脚本文件，因此任一包缺失时仍可独立启动。联合启用时，服务器菜单会自动出现“诡秘非凡秘典”，商店和抽奖也会自动加入 LOTM 商品；LOTM 的非凡伤害会继续遵守服务器领地权限。

另提供独立可选包 **Apocalypse Mobs v0.7.1**：实现主世界区域刷怪、五类感染者、持枪掠夺者、LootNode、分级怪物掉落和 SpawnDirector 跨包刷怪接口。它可独立运行；与 SAPI Server 同时启用时自动将管理保护区视为安全区并接入 `money` 经济，与 Test Guns 同时启用时支持闪盾致盲/失能、盾牌减伤及枪械半成品掉落。源码与安装包位于 `apocalypse_mobs_addon/`。

新增独立可选包 **Survival Daily & World Events v0.15.1**：每天生成采集、击杀、动态事件和综合四类委托，提供每日新闻、原生 NPC 对话、四类可配置商人、区域事件、多副本及神话物资箱密钥。无品质废墟物资箱会以约每 6 个新区块一个的概率自然生成；管理员也可临时开启旧区块补生成，处理已经探索的地图。刷怪笼替换只检查地表上下 6 格及玩家上 6/下 12 格。源码与安装包位于 `daily_world_events_addon/`。

## 📌 功能概览

### 1. 💰 经济系统 (Economy)
- **原生计分板绑定**：货币绑定原版 `money` 计分板，完全兼容原版命令与侧边栏显示。
- **玩家安全转账**：图形化选择在线玩家，支持自定义转账金额与防作弊检查。
- **财富排行榜**：实时查看服务器前 10 名富豪榜单与个人资产。
- **初始启动金**：新玩家进服自动赠送初始金币（默认 1000 金币）。

### 2. 🛒 分类商店系统 (Shop)
- **多分类商城**：建筑方块、矿石资源、农牧食物、战斗装备、珍品专区。
- **双向交易支持**：
  - 🟢 **购买**：选择商品及购买数量 (1~64)，自动扣除金币并发放物品。
  - 🔴 **回收出售**：支持玩家出售多余建材、矿物与战利品换取金币。

### 3. 🛡️ 地皮领地保护系统 (Land Protection)
- **区块级地皮体系**：以 16×16 区块为单位认领专属地皮。
- **全方位防熊防爆**：
  - 🚫 拦截非信任玩家破坏方块 (`playerBreakBlock`)
  - 🚫 拦截非信任玩家放置方块 (`playerPlaceBlock`)
  - 🚫 拦截打开箱子、木桶、潜影盒、熔炉、漏斗、门、拉杆等设施
  - 🚫 爆炸保护：自动拦截苦力怕、TNT 等爆炸摧毁领地方块
  - 🚫 拦截触碰展示框与盔甲架
- **领地管理功能**：
  - 👥 **信任成员**：可添加或移除好友共建权限。
  - ⚙️ **权限细分**：可单独开启/关闭访客破坏、放置、开箱或爆炸权限。
  - 🚀 **领地列表与传送**：一键传送至自己拥有的任一地皮。
  - 👁️ **边界粒子高亮**：沿 16×16 区块边界生成显眼绿色粒子。
  - 💰 **地皮回收出售**：支持按 70% 比例返还金币。

### 4. 🎁 幸运抽奖系统 (Lottery / Gacha)
- **多等级奖池**：
  - 🪙 **普通金币奖池**：抽取日常实用建材、矿物与高性价比食物。
  - 👑 **高级欧皇奖池**：抽取限定神话枪械【雷霆聚能炮】、下界合金锭、不死图腾、附魔金苹果、潜影盒、鞘翅与下界之星！
- **单抽与十连抽**：支持 1 次抽取与 10 连特惠抽取。
- **欧皇全服广播**：抽中【史诗】、【传说】与【神话限定】奖品时触发全服跑马灯公告。
- **防爆仓机制**：背包满时自动将掉落物安全生成在玩家脚下。
- **管理员自定义奖池**：管理员控制台可创建、编辑、停用或删除奖池，自定义名称、说明、图标、单抽/十连价格及奖品。
- **自定义奖品参数**：支持设置物品 ID、显示名、数量、权重和稀有度；保存时校验物品是否已经注册。
- **独立保底**：每个自定义奖池可指定一个保底奖品和触发抽数；每名玩家的每个奖池分别持久化计数，提前抽中指定奖品会重置。

### 5. 🏪 玩家交易寄卖行

- **自由寄卖**：玩家从背包选择物品、数量和每件单价，上架后由系统托管。
- **分批购买与撤回**：买家可以购买部分库存；卖家可无手续费撤回尚未售出的商品。
- **10% 成交费率**：成交时卖家获得总价的 90%，其余 10% 由系统扣除。
- **离线结算**：卖家离线期间产生的成交款会保存，并在下次上线时自动到账。
- **数据保护**：保留物品标识符、名称和 Lore；允许寄卖耐久未损耗的武器，已有耐久损耗、附魔或物品动态属性的物品仍禁止寄卖。
- **自定义名称**：卖家上架时可填写最多 32 字的寄卖名称；浏览和购买页面同时显示真实物品信息，成交后物品原名不会被修改。

### 6. ⚡ 抽奖限定武器：【雷霆聚能炮】(Thunder Blaster)
- **获取途径**：仅在【高级欧皇奖池】极低概率（神话品质）抽取，或管理员面板直接发放。
- **武器特性**：
  - 💥 **超强杀伤**：瞬发造成 **35 点高额聚能伤害**。
  - 🎯 **超远射程**：**50 格** 射线瞬发打击，附带强力击退。
  - ⚡ **炫酷特效**：发射贯穿视角的雷霆闪电光束，命中发生聚能粒子爆炸与专属充能音效。
  - 🔄 **手持长按/右键**：0.4 秒疾速连发射击，无限能量弹药！

### 7. 🧭 免费传送、主城保护与管理员控制台
- **免费公共传送**：管理员可创建最多 50 个公共传送点并设置主城出生点；传送不会查询或扣除金币。
- **安全落点**：传送前会在目标坐标上下搜索安全站立位置，避开水、岩浆和窒息方块。
- **主城保护区**：管理员用 A/B 两点划定任意长方体区域，默认禁止破坏、放置、PVP、爆炸和玩家地皮认领。
- **区域优先级**：管理员保护区优先于玩家地皮；管理员或 OP 可绕过操作限制。
- **私人 Home**：每名玩家默认可保存 3 个私人位置，同名设置会覆盖原位置。
- **双向 TPA**：支持请求传送到玩家或邀请玩家传送过来；目标玩家必须明确接受，请求默认 60 秒过期。
- **TPA 双层开关**：管理员可全局关闭 TPA，或分别关闭“请求过去/邀请过来”；玩家也可拒绝接收请求，关闭后自动清理不再允许的待处理请求。
- **死亡返回**：自动记录最近一次死亡位置，玩家可免费、安全地返回一次，成功后才清除记录。
- **管理与审计**：记录公共传送、Home、TPA、死亡返回、地皮与关键管理员操作；管理员可搜索、查看、输出或清空最近 200 条记录。
- **七日签到**：按服务器时区判断自然日，默认第 1～7 天分别获得 2000、2500、3000、3500、4000、5000、8000 金币，第七日另有额外物品；管理员可配置开关、时区和奖励。
- **兑换码运营**：管理员可创建金币与物品组合礼包码，设置全服次数、每人次数、期限及启停状态；玩家通过菜单私密输入。
- **待领取奖励**：奖励暂时无法发放时自动进入玩家奖励箱，玩家可重试领取，管理员可为在线玩家检查、重发或清理。
- **多种唤起方式**：
  - 🎯 手持 **罗盘** (`minecraft:compass`) 右键直接弹出菜单。
  - 💬 聊天栏输入指令：`!menu`, `!shop`, `!land`, `!lottery`, `!market` / `!ah`, `!pay`, `!money`, `!warp`, `!spawn`, `!home`, `!tpa`, `!back`, `!daily`, `!redeem`。
  - ⚡ 运行命令：`/scriptevent system:menu`。

## 🛠️ 安装与使用指南

1. 下载并双击导入 `sapi_server_addon/SAPI_Server_Addon.mcaddon` 与根目录的 `LOTM_Pathways_Addon.mcaddon`。
2. 创建或编辑世界，在行为包中启用 `SAPI Server Economy` 与 `LOTM Pathways`；LOTM 资源包会由依赖自动启用。
3. 确保世界设置中的 **Beta API（测试版 API）** 选项已开启。
4. 进入世界后手持罗盘右键打开服务器菜单；只安装 LOTM 时，罗盘会直接打开非凡秘典。

也可以按需求单独安装：

- 纯生存经济服务器：只安装 `sapi_server_addon/SAPI_Server_Addon.mcaddon`。
- 纯诡秘玩法世界：只安装 `LOTM_Pathways_Addon.mcaddon`。
- 完整联动服务器：两个 `.mcaddon` 都安装并启用。
- 末日主世界：在 SAPI 基础上额外安装 `Test_Guns_2D_Addon.mcaddon`、`Apocalypse_Mobs_Addon.mcaddon` 与 `Survival_Daily_Events_Addon.mcaddon`；后三者仍可按需单独启用。

> Script API 1.19.0 稳定版没有公开 `chatSend` 事件，因此该版本请使用罗盘或
> `/scriptevent system:menu` 打开菜单；聊天快捷指令只会在运行时提供聊天事件时启用。
> 领地放置保护在 1.19.0 上使用放置后立即回滚模式，并向非创造玩家返还被撤销的方块。

### 赋予管理员权限
在游戏聊天栏执行以下指令赋予自己管理权限：
```mcfunction
/tag @s add admin
```
或直接通过控制台给予 OP 权限。

进入罗盘菜单的“管理员控制台”后：

1. 在“公共传送点管理”中设置主城出生点，或在当前位置创建公共传送点。
2. 在“主城与保护区管理”中分别设置选点 A、选点 B，再创建主城保护区。
3. 玩家从罗盘的“公共传送点”进入，或使用 `!warp` / `!spawn`；所有传送均免费。
4. 玩家从“个人传送”使用 Home、TPA 和死亡返回；管理员可在控制台管理在线玩家的传送数据并查看审计日志。
5. 玩家从“每日福利”签到、输入兑换码和领取暂存奖励；管理员从“服务器运营管理”配置签到与兑换码。

## ⚙️ 自定义配置指南

所有商品、价格、抽奖掉落、地皮单价均可在 [sapi_server_addon/sapi_server_bp/scripts/config.js](sapi_server_addon/sapi_server_bp/scripts/config.js) 中轻松修改：
- **修改货币名称**：`Config.economy.currencyName`
- **修改地皮价格**：`Config.land.pricePerChunk`
- **新增商店商品**：在 `Config.shop.categories` 的 `items` 数组中添加物品 ID、名称与买卖价格。
- **自定义抽奖奖品与权重**：在 `Config.lottery.pools` 中增减物品与配置 `weight`。

## 📦 重新构建安装包

修改源码后，在 macOS 或 Linux 中运行：

```bash
bash scripts/build-packages.sh
```

只构建 SAPI Server 时运行：

```bash
bash sapi_server_addon/build.sh
```

脚本会生成并校验：

- `sapi_server_addon/SAPI_Server_BP.mcpack`、`sapi_server_addon/SAPI_Server_Addon.mcaddon`
- `LOTM_Pathways_BP.mcpack`、`LOTM_Pathways_RP.mcpack`、`LOTM_Pathways_Addon.mcaddon`

末日生存可选包分别运行：

```bash
bash apocalypse_mobs_addon/build.sh
bash daily_world_events_addon/build.sh
```

旧的单体 `SAPI_System_Addon.mcaddon` 会在构建时删除，避免玩家同时启用新旧入口导致事件重复订阅。
